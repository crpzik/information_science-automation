## 笔记

由本人学习期间根据授课 PPT 整理，包含课堂例题，以及学习《电磁学千题解》时记录的部分结论。内容可能存在错误或遗漏，仅供参考。

## 参考资料

《电磁学千题解》习题覆盖较全面，内容循序渐进，并包含一些有用的结论，适合作为电磁学 C 的补充练习。

根据部分同学的反馈，该书对电磁学 A、B 的参考价值可能相对有限。近年来电磁学 C 的考试风格与书中习题也存在一定差异，但其对课程内容的整体学习仍有很大帮助。
