# Information Science and Automation Course Materials

## 简介

本人为中国科学技术大学信息科学技术学院 2023 级自动化专业学生。

本仓库用于整理本科阶段的课程学习资料，方便个人复习，也供后续学习者参考。内容主要包括本人撰写的课程笔记、作业与学习总结，以及从课程或公开渠道收集的参考资料。

各课程文件夹中的 `README.md` 包含相应的课程说明、资料来源和使用提示，建议在使用前查阅。
